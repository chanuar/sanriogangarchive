### The project

Made for **SanrioGang Archive**, with the group's pink graffiti logo at the heart of its visual identity. Underground trap, raw photos, video fragments and lore — collected in a digital collage of our own.

<details>
<summary><strong>Run locally</strong></summary>

Requires Node.js 22.12+ and npm.

```sh
npm ci
npm run dev -- --background
```

Open http://localhost:4321. Build with `npm run build` or stop the server with `npm run astro -- dev stop`.
